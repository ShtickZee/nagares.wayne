## 🌟 Highlights & Features

* **Flagship Spotlight: NiyoSense:** Detailed showcase of the agricultural intelligence platform featuring dual YOLOv8 models, on-device 8-bit TFLite inference, offline-first Flutter client, and a Django 6.1 REST backend.
* **Interactive 70/30 Late Fusion Simulator:** In-browser widget allowing visitors to test multimodal decision rules and sensor guardrails (HSV filter, cadence gate, conflict veto) live.
* **ATS-Optimized Resume Viewer:** Instant in-browser resume preview with a one-click PDF print/export handler.
* **Automated CI/CD:** Ready-to-go GitHub Actions workflow for zero-downtime deployment to GitHub Pages.

---

## 🛠️ Quick Start

```powershell
# 1. Install dependencies
npm install

# 2. Start local development server (http://localhost:5173/)
npm run dev

# 3. Build for production (outputs to /dist)
npm run build

# 4. Preview production build (http://localhost:4173/)
npm run preview
```
